# inner beforeShowPromise(services, elementSelector, maxWaitTime) → {function}

Creates a promise function that waits for an element to be visible before showing a guide step. This function will be called before showing a step. The step will be shown after the promise resolves. It waits for the element of the step to be visible on the page.

Parameters:
Name Type Description
services Object

The services object containing GuideUtils, toastr, and $translate

CSS selector for the element to wait for
